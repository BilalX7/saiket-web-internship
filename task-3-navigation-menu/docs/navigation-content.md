## Accessibility-oriented content notes

- Keep the visible navigation labels concise and identical to the destination concepts.
- Preserve the full `Main navigation` accessible name and the written heading hierarchy; do not replace headings with decorative text.
- No real icon is proposed. Prefer CSS-only decorative lines or waypoint shapes, which should be ignored by assistive technology and require no text alternative.
- If a meaningful icon is introduced later, give it an accessible name only when the adjacent visible text does not already provide the same meaning. Decorative icons must have an empty text alternative or be hidden from the accessibility tree, as appropriate to their implementation.
- Do not use the word “button” for these links; they navigate to locations rather than performing actions.
