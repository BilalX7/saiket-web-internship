# SaiKet Systems Web Development Internship

This repository is organized as a set of independent internship tasks. Each task belongs in its
own sibling directory so its source, assets, and review history remain easy to inspect.

## Internship tasks

- [`task-1-portfolio/`](./task-1-portfolio/) — Bilal Koubar's single-page professional portfolio,
  built with semantic HTML, modern CSS, and dependency-free vanilla JavaScript.
- [`task-2-ecommerce-product-page/`](./task-2-ecommerce-product-page/) — a responsive product-page
  and accessible demonstration cart for the fictional MONOFORM M75, built with the same dependency-free
  technology stack. It is not a real storefront.
- [`task-3-navigation-menu/`](./task-3-navigation-menu/) — WAYMARK Studio, a fictional studio page
  demonstrating native section navigation with HTML and CSS only.
- [`task-4-html-forms/`](./task-4-html-forms/) — FORM & FIELD, a fictional HTML form and validation
  demonstration. The application does not send or store entered data.

The GitHub Pages workflow is configured to publish all four tasks in one artifact:

- Task 1 remains at the [Pages root](https://bilalx7.github.io/saiket-web-internship/).
- Task 2 remains at its [product page URL](https://bilalx7.github.io/saiket-web-internship/task-2-ecommerce-product-page/).
- Task 3 remains at its [navigation menu URL](https://bilalx7.github.io/saiket-web-internship/task-3-navigation-menu/).
- Task 4 is configured for its [planned form URL](https://bilalx7.github.io/saiket-web-internship/task-4-html-forms/).
  Publication is pending Phase B.

Task 2 is a fictional product and cart demonstration, not a real storefront.
